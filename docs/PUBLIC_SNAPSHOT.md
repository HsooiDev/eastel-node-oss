# Public source snapshot

This repository contains source for the application at https://eastel.site. It was
initialized from reviewed files with an independent history and uses real publication
and commit dates. It is not a live environment inventory or a promise that every later
website change is included.

Original code and documentation use AGPL-3.0-only. Preserve the copyright, licence,
font and third-party notices. Public business contacts and authorized brand assets
are distinct from private account identities or service credentials.

Keep credentials, customer data, personal machine paths, private deployment records,
logs and backups out of this repository. Generic test hosts and synthetic fixtures
are examples, not credentials or a list of Eastel environments. See
[publication hygiene](OPEN_SOURCE_PREPARATION.md).
